# VrLissi

VrLissi est un jeu de type party game en solo dans lequel le joueur devra effectuer différents mini-jeux pour gagner des pièces et construire sa ville. L’entrée dans les mini-jeux se fait via un objet de la vie courante tel qu’un téléphone, une règle et d'autres.

## Finalité

La finalité est de laisser aux joueurs la possibilité de choisir un objet qui l'amènera vers un mini-jeux, son but sera alors de tous les essayer et de tous les trouver. Du côté des développeurs, le but est de laisser la possibilité de choisir l’objet et le mini-jeux qu’il souhaite pour que chacun puisse créer ce qu’il veut en ayant une base. Par la suite, ces mini-jeux rapportent des pièces qui pourront être utilisées pour acheter des maisons, des objets de décoration, des bâtiments pour construire sa ville.


## Si vous utilisez un Occulus Quest :
1. Télécharger Unity et importer le projet dessus
2. Télécharger steam et l'appication steam VR
3. Télécharger le setup occulus disponible ici : https://drive.google.com/file/d/1AMpODH-CYhf19e4O5DiJwjbAPFRPFfr4/view?usp=sharing

## Jouer
1. Brancher votre casque a votre ordinateur
2. Accepter le Quest Link qui s'affichera sur l'écran du casque
3. Lancer Steam Vr
4. Lancer le jeu
